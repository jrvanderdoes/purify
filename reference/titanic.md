# Sample Titanic Data

Data about passengers on the titanic.

## Usage

``` r
titanic
```

## Format

### `titanic`

A data frame with 714 rows and 5 columns:

- Survived:

  Bernoulli variable (0 or 1) if passenger survived.

- Pclass:

  Class of passenger, values of 1,2,3.

- Sex:

  Sex of passenger, 'male' or 'female'.

- Age:

  Age of passenger

- Parch:

  Number of Parents/Children Aboard

## Source

Hendricks P (2015). *titanic: Titanic Passenger Survival Data Set*. R
package version 0.1.0, <https://CRAN.R-project.org/package=titanic>.
